# My Finance

Sifir-Bilgi (Zero-Knowledge) prensibiyle calisan, tamamen tarayici ici (client-side) calisan Akbank ve Garanti BBVA PDF/TXT ekstre analiz araci.

## Ozellikler
- **Gizlilik Odakli:** Verileriniz hicbir sunucuya gonderilmez, RAM uzerinde islenir.
- **Yapay Zeka OCR:** Bozuk PDF leri Tesseract.js ile otomatik tarar ve okur.
- **Gelismis Grafikler:** Recharts ile donatilmis 7 farkli etkilesimli finansal grafik.

## Kurulum
```bash
npm install
npm run dev
```

## Derleme (Production)
```bash
npm run build
```
